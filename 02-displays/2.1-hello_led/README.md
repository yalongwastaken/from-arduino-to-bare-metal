# 2.1 — Hello, LED!

Blink an LED on GPIO26. The embedded equivalent of "Hello, World."

SunFounder tutorial: [2.1 Hello, LED!](https://docs.sunfounder.com/projects/esp32-starter-kit/en/latest/arduino/2_display.html#hello-led)

## Circuit

- LED anode → 220Ω resistor → GPIO26
- LED cathode → GND
